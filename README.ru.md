# mimodel-tool

[English](README.md) | **Русский**

Конвертер моделей Minecraft в формат **Mine-imator** (`.mimodel` + `.png`).
Подходит для Mine-imator 2.0.x, и сборок на его основе.

Берёт модели прямо из:

* **jar мода** (Fabric / Forge / NeoForge / Quilt);
* **jar клиента Minecraft** (ванильные блоки, предметы и сущности);
* **ресурспака** (`.zip` или папка), в том числе OptiFine CEM (`.jem`/`.jpm`, например Fresh Animations);
* отдельных файлов `.bbmodel` (Blockbench) и `.geo.json` (Bedrock / GeckoLib).

Версии Minecraft: **1.20 – 26.3**.

## Что конвертируется

| Тип | Откуда | Как |
|---|---|---|
| Блоки, предметы | `assets/*/models/**.json` | наследование `parent`, текстуры, повороты элементов (в т.ч. новый формат 26.x), окраска травы/листвы; плоские предметы (`item/generated`) -> объёмная модель из пикселей |
| Сущности Minecraft | jar клиента | геометрия берётся из самого Minecraft (точно как в игре) |
| Модели из кода мода | `.class` в jar мода | безопасная интерпретация байткода `create…Layer()` / `getTexturedModelData()` (код мода **не запускается**) |
| GeckoLib / Bedrock | `*.geo.json` | кости, кубы, pivot, поворот, inflate, mirror, per-face UV |
| Blockbench | `*.bbmodel` | группы, кубы, встроенные текстуры, box UV и per-face UV |
| OptiFine CEM | `*.jem`, `*.jpm` | модели ресурспаков (Fresh Animations и т.п.) |

Если UV модели не укладывается в коробочную развёртку Mine-imator (per-face UV, масштаб текстуры, скрытые грани), текстура автоматически перепекается в отдельный атлас - внешний вид сохраняется.

## Графический интерфейс

Запустите `mimodel-tool.exe`.

1. **Добавить файлы…** (или перетащите файлы в окно) - моды, клиент Minecraft, ресурспаки. Можно указать целую папку `mods`.
2. Найдите модель в дереве (поле **Поиск**). Справа - 3D-превью:
   ЛКМ - вращать, ПКМ - сдвигать, колесо - масштаб, двойной щелчок - сброс.
3. Для сущностей и моделей из кода текстура подбирается автоматически; в списке **Текстура** можно выбрать другую или свой PNG.
4. **Экспорт выбранных…** (можно выделить несколько моделей или целую папку) или **Экспорт всех (по фильтру)…**.
5. В Mine-imator: **Импорт** (Ctrl+I) -> выберите файл `.mimodel`.

**Вид -> Язык** - English (по умолчанию) или Русский. **Вид -> Тема** - тёмная (по умолчанию), светлая или системная. Настройки запоминаются.

**Версия MC** - какую версию Minecraft использовать для недостающих ванильных файлов (родительские модели, текстуры, классы). Авто - версия берётся из мода/ресурспака.
**Скачивать файлы Minecraft** - при необходимости клиент нужной версии скачивается с серверов Mojang один раз и кэшируется (`%LOCALAPPDATA%\mimodel-tool\cache`). Если установлен лаунчер Minecraft, используются файлы из `.minecraft`.

## Командная строка

`mimodel-tool-cli.exe` (или `java -jar mimodel-tool-all.jar …`):

```
mimodel-tool-cli list    <источники...> [--type T] [--filter ТЕКСТ]
mimodel-tool-cli export  <источники...> --model ID [--texture ФАЙЛ.png] --out ПАПКА
mimodel-tool-cli export-all <источники...> --out ПАПКА [--type T] [--filter ТЕКСТ]
mimodel-tool-cli textures <источники...> --model ID
mimodel-tool-cli versions
```

Типы: `block, item, json, entity, java, geo, bbmodel, cem`. Параметры: `--mc ВЕРСИЯ`, `--offline`, `--no-tint`, `--no-entities`, `--lang en|ru` (язык; также переменная `MIMT_LANG`), `-v`.

Примеры:

```
mimodel-tool-cli list mods\naturalist.jar --type geo,java
mimodel-tool-cli export mods\friendsandfoes.jar --model "java:..." --out out
mimodel-tool-cli export-all FreshAnimations.zip --type cem --out out\fa
mimodel-tool-cli export-all %APPDATA%\.minecraft\versions\1.21.1\1.21.1.jar --type entity --out out\vanilla
```

## Ограничения

* Экспортируется **поза покоя** (без анимаций) - анимируйте в Mine-imator.
* Модели, собранные кодом мода, извлекаются по возможности: если метод модели зависит от данных, недоступных без запуска игры, модель пропускается (см. журнал).
* Текстуры сущностей в Minecraft выбираются в коде рендера, поэтому для них текстура **угадывается** по имени - при ошибке выберите нужную вручную.
* Блоки с особым рендером (сундуки, таблички, шалкеры, кровати и т.п.) - это сущности блоков.
* Для ванильных данных нужен интернет один раз (или установленный Minecraft нужной версии).
* Для запуска jar напрямую нужна Java 25+ (сборка для Windows уже содержит Java).
